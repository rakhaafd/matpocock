# Issue tracker: Local Markdown

Issues and specs for this repo live as markdown files in `.scratch/`.

## Conventions

- Feature folder: `.scratch/financial-tracker/`
- Wayfinder Map: `.scratch/financial-tracker/map.md`
- Decision issues: `.scratch/financial-tracker/issues/NN-<slug>.md`
- Implementation tickets: `.scratch/financial-tracker/tickets/NN-<slug>.md`
- Spec: `.scratch/financial-tracker/spec.md`
